 Calculator in C

A simple command-line calculator built using C programming language.  
This project performs basic arithmetic operations with proper input validation and error handling.

---

 Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation (handles invalid input)
- Division by zero protection
- User-friendly menu-driven interface



 Technologies Used

- C Programming Language
- Standard Input/Output (stdio.h)



 How It Works

1. User selects an operation from the menu  
2. Enters two numbers  
3. Program performs calculation  
4. Displays result  
5. Repeats until user exits  
 How to Run
   Step 1: Compile the code
```bash
